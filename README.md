# Maryam Ghaffar – Professional Portfolio

A modern, responsive, and fully functional portfolio website built with **HTML, CSS, and JavaScript**. It showcases my skills, projects, certifications, education, and provides an easy way for clients and recruiters to contact me.

🔗 **Live Website:** [https://maryamghaffar1234m-png.github.io/Maryam_Portfolio/](https://maryamghaffar1234m-png.github.io/Maryam_Portfolio/)

---

## ✨ Features

- **Hero Section** – Typing animation, availability badge, floating stats.
- **About Me** – Professional summary with key highlights.
- **Services** – 5 freelance services covering Frontend, Web Development, and Generative AI.
- **Technical Skills** – 13 skills with correct Font Awesome icons and proficiency levels.
- **Work Experience** – Timeline layout with internship and teaching experience.
- **Education** – Separate section for degree and certifications.
- **Projects** – 9 real projects with real screenshots, filterable categories, and Live Demo links where available.
- **Certifications** – 4 certificates with clickable images (modal popup).
- **Contact Form** – Opens Gmail compose directly (no backend required).
- **Responsive Design** – Works on mobile, tablet, and desktop.
- **Smooth Animations** – Scroll reveal, hover effects, typing effect.
- **Dark Theme** – Modern glassmorphism UI with gradient accents.

 2. Open index.html in your browser.
 3. That's it – no build step required.
    
🧩 Easy Updates
All dynamic content is stored in JavaScript arrays in script.js:

servicesData – Add/remove services.

skillsData – Add/remove skills (with iconType: 'fab' for brand icons or 'fas' for solid icons).

experienceData – Add/remove work experience.

educationData – Add/remove education entries.

projectsData – Add/remove projects (with optional screenshot and liveLink fields).

certData – Add/remove certifications.

Simply edit the arrays and the website updates automatically.
